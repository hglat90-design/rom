# فيسي برو (Veysi Pro) - تطبيق الدردشة ونظام البلاغات المتطور

تطبيق دردشة عصري فائق السرعة مبني بكود نظيف (Clean Code) ومعمارية معيارية قابلة للنشر الفوري على **Netlify** أو **GitHub Pages** دون أي شاشات بيضاء أو مشاكل في المسارات.

---

## 🚀 المميزات الرئيسية

1. **غرف الدردشة العامة (Public Chat Room):**
   - رسائل فورية فائقة السرعة مع أصوات ناعمة مبنية بمكتبة Web Audio API.
   - دعم كامل للصور، مقاطع الفيديو، وتضمين فيديوهات يوتيوب التفاعلية.
   - نظام الردود والاقتباسات (Reply System).
   - رتب المستخدمين: مالك 👑، مدير 💎، مشرف 🛡️، موثوق ✅، عضو عادي.
   - فقاعات رسائل مخصصة وأكثر من 20 حركة وتأثير نصي للاسم (Shine, Rainbow, Neon, Fire, Ice, Gold, Aurora, etc.).

2. **الرسائل الخاصة (Direct Messages - DM):**
   - محادثات فردية مشفرة ومحمية محلياً وعبر المتصفحات المتعددة.
   - شارات وصول وقراءة الرسائل بدقة (✓✓ و ✓✓ باللون الأزرق).
   - قائمة المحادثات مع عدد الرسائل غير المقروءة.
   - لوحة مراقبة الخاص للمالك والمدير (DM Monitor).

3. **الحالات والقصص (Stories & Statuses):**
   - نشر حالات نصية أو وسائط (صور وفيديوهات) صالحة لمدة 24 ساعة.
   - عارض قصص سينمائي مع عداد زمني، تنقل بالأسهم، وقائمة من شاهد حالتك.

4. **الأمان ولوحة الإدارة المتطورة:**
   - بوابة التوثيق برقم الهاتف وربط مع بوت تليجرام الرسمي (`@veysi_otp_bot`) أو تخطي سريع.
   - نظام الموافقة الإدارية على طلبات التسجيل الجديدة.
   - لوحة بلاغات متكاملة لتصنيف المحتوى المسيء وحل البلاغات (حظر، كتم، رفض).
   - نظام التحذيرات العاجلة (Emergency Broadcast): شاشة كاملة إجبارية مع تتبع وقت القراءة والتأكيد.
   - وضع الصيانة مع تخصيص الرسالة وقائمة المختبرين المسموح لهم بالدخول.

5. **تخصيص المظهر (Customizer):**
   - تحكم كامل بألوان الشريط العلوي والسفلي مع قوالب جاهزة.
   - مكتبة خلفيات دردشة متنوعة + إمكانية رفع خلفية مخصصة.
   - تأثيرات بيئية متحركة (نجوم، قلوب، ورود، ثلج، نار، عملات ذهبية، فقاعات).

## 📁 هيكلية الملفات (File Structure)

```
.
├── index.html              # ملف المدخل الرئيسي بمسارات نسبية ./ (جاهز لـ Netlify & GitHub Pages)
├── metadata.json           # بيانات التطبيق والصلاحيات
├── package.json            # التبعيات وأوامر البناء
├── vite.config.ts          # إعدادات Vite مع base: './' للمسارات النسبية
├── README.md               # دليل التشغيل والربط بمستودع GitHub
└── src/
    ├── style.css           # ملف التنسيقات الكامل والنظيف
    ├── types.ts            # واجهات TypeScript لضمان الأمان البرمجي
    ├── audio.ts            # مولد الأصوات الفوري (Web Audio API)
    ├── storage.ts          # طبقة الحفظ والمزامنة بين النوافذ (BroadcastChannel)
    ├── effects.ts          # محرك التأثيرات والجسيمات العائمة
    ├── chat.ts             # منطق الدردشة العامة ومعالجة الرسائل
    ├── dm.ts               # منطق الرسائل الخاصة ومراقبة الخاص
    ├── status.ts           # نظام الحالات والقصص وعارضها
    ├── admin.ts            # أدوات الإشراف، البلاغات، التحذيرات والأمان
    ├── customizer.ts       # مخصص الألوان والخلفيات والحركات
    ├── auth.ts             # إدارة الدخول والتوثيق وحالات الحظر
    └── main.ts             # المتحكم الرئيسي وربط جميع الأحداث
```

## 🛠️ كيفية التشغيل محلياً (Local Development)

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 🌐 النشر على GitHub و GitHub Pages / Netlify

### 1. الرفع إلى مستودع GitHub:
```bash
git init
git add .
git commit -m "Initial release of Veysi Pro clean codebase"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### 2. النشر على GitHub Pages:
- اذهب إلى إعدادات المستودع **Settings** > **Pages**.
- في قسم **Build and deployment**، اختر النشر عبر GitHub Actions أو من مجلد `dist` بعد تشغيل `npm run build`.
- التطبيق مضبوط بالفعل مع مسار نسبي `./` ليعمل بسلاسة تامة.

### 3. النشر على Netlify:
- اسحب المستودع في Netlify (أو اسحب مجلد `dist` مباشرة عبر Netlify Drop).
- في حقل **Build command**: اكتب `npm run build`
- في حقل **Publish directory**: اكتب `dist`
- سيعمل التطبيق فوراً بدون أي شاشات بيضاء.
